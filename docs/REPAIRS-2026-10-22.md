# QA repairs — 22 October 2026 (verification completed 23 October)

This continues the findings in [the original QA report](QA-REPORT-2026-10-22.md). Repairs are in the local project. No hosted Supabase database or external provider configuration has been changed.

## Functional repairs

| Finding | Repair | Verification |
| --- | --- | --- |
| F1: user preview crashes over phone LAN HTTP | Generate secure UUIDs with `crypto.getRandomValues`, which is available on the LAN HTTP origin, instead of requiring `crypto.randomUUID`. | UUID fallback/version/variant/uniqueness regression tests; browser results below. |
| F2: deleted user's subject remains in administrator delivery jobs | Remove every delivery job linked to the deleted user's appointments, regardless of recipient. Push receipts cascade with their job. Migration also scrubs jobs for accounts already marked Deleted. | Regression checks administrator and user jobs plus a linked push receipt. |
| F3: NULL deletion confirmation bypass | Use a null-safe comparison against the exact confirmation text. | NULL rejected and profile remains Active. |
| F4: exhausted interrupted job remains Pending forever | Mark exhausted Pending or expired Processing jobs Failed. Recover retryable leases and preserve fresh Processing leases. | Final-attempt recovery and retryable/live lease regression checks. |
| F5: NULL availability wipes working days | Require all three JSON arguments to be arrays before modifying data; retain seven-weekday and table validation. | NULL, object and invalid-rule inputs rejected atomically; existing rules retained. |
| F6: server accepts malformed meeting links | Share full URL validation rules between the web/native client and database. Add a constraint for new approved online appointment writes. | Client/database agreement across valid and invalid URLs; embedded whitespace rejected. |

## Accessibility repairs

- Closed mobile navigation uses `visibility: hidden`, removing its controls from keyboard focus. Open navigation receives focus, traps Tab/Shift+Tab, closes with Escape or its close button, and restores focus to the menu trigger.
- Preview role-switch buttons now have a minimum height of 44 pixels and a visible keyboard focus outline.
- Native muted text changed from `#83988a` to `#526b5d`: contrast is **5.80:1** against white and **5.47:1** against the screen background. Native badge text/background pairs now exceed **5.67:1**. Error text was also darkened. Calculations are saved in `repairs-2026-10-22/contrast.json`.
